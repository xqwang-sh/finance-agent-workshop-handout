Building a new agent prompt from scratch

把刚才的演示收束成四个动作

01从最小 prompt 开始

写清 role、data、task、definition of done 和 output shape。

02先跑 eval，再看失败模式

失败不是一句“模型不行”，而是下一轮要观察的证据。

03只为失败加规则

优先增加字段、工具或检查条件，少写长 ban list。

04需要结构就拆成系统

分类、规划和执行变复杂时，走向多次模型调用。

03 / Eval

五个真实案例，按 approach 一行一行跑

每点一次 Run row，就让这一行的 harness 依次面对五张证据卡；先看小模型为什么失败，再看工具能修什么、看图能修什么，以及第二来源何时必须阻断。
